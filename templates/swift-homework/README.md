# Домашнее задание

Реализуйте функции в `Sources/Orders/`. Везде, где сейчас стоит `fatalError("TODO")`, должен появиться ваш код.

## С чего начать

1. Возьмите токен в личном кабинете LMS и впишите его в `config.yml`:
   ```yaml
   user_token: ваш-токен
   ```
2. Пишите код в `Sources/Orders/`.
3. Прогоняйте тесты локально:
   ```bash
   swift test --parallel
   ```
4. Коммитьте и пушьте. Проверка запустится сама, результат виден во вкладке Actions.

Когда все тесты зелёные, задание автоматически засчитывается в LMS.

## Что нужно знать

- Требуется Swift 6 (Xcode 16+). В CI используется тот же Swift, но на Linux.
- Деньги везде в копейках, целым числом (`Int`). Не используйте `Decimal`.
- Ошибки возвращайте через `throw OrderError.invalidArgument(...)` и `throw OrderError.invalidState(...)` — так же, как в `OrderError.swift`.
- `Package.swift`, `Tests/` и `.github/` менять бессмысленно: при проверке они заменяются эталонными. Правьте только `Sources/Orders/` и `config.yml`.
- Если в Actions написано «проект не скомпилировался» — код не собирается. Проверьте `swift build` локально.
