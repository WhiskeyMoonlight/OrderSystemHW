# Домашнее задание

Реализуйте функции в `Sources/Orders/`. Везде, где сейчас стоит `fatalError("TODO")`, должен появиться ваш код.

## С чего начать

1. Возьмите токен в личном кабинете LMS и впишите его в `config.yml`:
   ```yaml
   user_token: ваш-токен
   ```
   Не добавляйте личный токен в публичный репозиторий.
2. Пишите код в `Sources/Orders/`.
3. Прогоняйте тесты локально:
   ```bash
   swift test --parallel
   ```
4. Коммитьте и пушьте. Проверка запустится сама, результат виден во вкладке Actions.

Когда проверка в Actions проходит, задание автоматически засчитывается в LMS.

## Тесты и проверка

- **Тесты в `Tests/` — ваши.** Запускайте их когда угодно, меняйте, добавляйте свои. У курса может быть свой набор проверок.
- **Засчитывает задание только проверка в Actions.** Чекер собирает только `Sources/Orders/` и запускает заранее собранные тесты курса. Он не использует ваш `Tests/` и `Package.swift`.
- **Локально зелёно, а в Actions красно?** Откройте вывод Actions: там видно, не собралось ли решение или какой тест упал.

## Что нужно знать

- Требуется Swift 6 (Xcode 16+). В Actions используется Swift 6.1.3 на Linux. Сохраняйте публичные сигнатуры задания и не добавляйте зависимости, которых нет в стандартном тулчейне.
- Деньги везде в копейках, целым числом (`Int`). Не используйте `Decimal`.
- Ошибки возвращайте через `throw OrderError.invalidArgument(...)` и `throw OrderError.invalidState(...)` — так же, как в `OrderError.swift`.
- Не трогайте `.github/` (там проверка) и не удаляйте `config.yml` (там ваш токен).
- Если в Actions не удалось собрать модуль `Orders`, проверьте вывод компилятора и попробуйте `swift build` локально.
