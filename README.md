# course-checker

Чекер домашних заданий. Это один самодостаточный бинарь, который **мы собираем при подготовке ДЗ** и кладём в репозиторий задания (`.github/checker`). Для Swift в него вшит уже собранный XCTest: в GitHub Actions чекер компилирует решение, запускает этот XCTest и при успешном прогоне засчитывает задание в LMS.

Тесты в репозитории студента можно запускать и менять локально. В штатном CI зачёт отправляет чекер после прогона эталонного набора.

## Быстрый старт: Swift

С запущенным Docker и заданными в окружении `LMS_COMPANY_TOKEN` и `CALLBACK_TASK_ID` запустите:

```bash
./build.sh swift "/путь/к/проекту/Tests/OrdersTests"
```

Готовый файл для CI — `dist/checker-swift-linux-amd64`. Можно также положить
свои тесты в `payload/swift/tests/OrdersTests/` и запустить `./build.sh swift`
без пути.

[Инструкция для автора задания](docs/SWIFT.md) объясняет, как сразу
установить бинарник, проверить его и настроить зачёт в LMS.

Чекер написан на Go. Для проверки Swift нужен Linux x86-64 с тулчейном Swift; версия зафиксирована в шаблоне workflow.

## Тулчейны

| Тулчейн | Как проверяет | Команда сборки |
|---|---|---|
| `gradle` | Подставляет JUnit-тесты и запускает Gradle | `./build.sh gradle` |
| `swift` | Компилирует решение и запускает предсобранный XCTest | `./build.sh swift` |

`INSTALL_TO=<путь к репозиторию задания>` установит Linux-бинарник сразу
в `.github/checker`.
