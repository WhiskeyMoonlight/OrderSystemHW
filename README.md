# course-checker

Чекер домашних заданий. Это один самодостаточный бинарь, который **мы собираем при подготовке ДЗ** и кладём в репозиторий задания (`.github/checker`). В бинарь вшиты эталонные тесты. В GitHub Actions он заменяет тесты студента эталонными, прогоняет их и при зелёном прогоне засчитывает задание в LMS.

Тесты в репозитории студента — обычные локальные тесты: студент может запускать и менять их как угодно. Засчитать задание может только бинарь.

## Быстрый старт: Swift

1. Положите эталонные тесты (`*.swift`) в `payload/swift/tests/OrdersTests/` — они вшиваются в бинарь. Копию для студентов положите в `templates/swift-homework/Tests/OrdersTests/`.
2. Соберите бинарь и сразу установите его в репозиторий задания:
   ```bash
   INSTALL_TO=<путь к репозиторию задания> \
   LMS_COMPANY_TOKEN=<токен> CALLBACK_TASK_ID=<id задания> ./build.sh swift
   ```
   Бинарь `dist/checker-swift-linux-amd64` будет скопирован в `<репозиторий>/.github/checker`.
3. Закоммитьте `.github/checker` вместе с заданием.

Подробно, включая разницу между локальными и эталонными тестами, правила для тестов и токены: [docs/SWIFT.md](docs/SWIFT.md).

Написан на Go, чтобы собираться в статический бинарь под Linux и macOS одной командой, без рантайма и зависимостей.

## Тулчейны

Язык задания задаётся каталогом в `payload/`:

```
payload/<id>/
├── toolchain.json   что и как запускать, куда класть тесты, где искать отчёт
├── tests/...        эталонные тесты → копируются в testsTargetDir проекта
└── pinned/...       необязательно: файлы, перезаписываемые в корне проекта
```

Чтобы добавить язык, нужен новый каталог — код на Go менять не нужно.

| Тулчейн | Задание | Команда сборки |
|---|---|---|
| `gradle` | Kotlin + Gradle, JUnit Platform | `./build.sh gradle` |
| `swift` | Swift + SwiftPM, XCTest | `./build.sh swift` |

## Сборка

```bash
LMS_COMPANY_TOKEN=<токен> CALLBACK_TASK_ID=<id задания> ./build.sh swift
```

Бинари появятся в `dist/checker-<тулчейн>-<os>-<arch>`. Для GitHub Actions нужен `linux-amd64`; `INSTALL_TO=<путь к репозиторию задания>` положит его сразу в `.github/checker`.
